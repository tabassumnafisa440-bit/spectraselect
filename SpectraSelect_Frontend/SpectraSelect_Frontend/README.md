# SpectraSelect Frontend

## Run in VS Code

1. Extract the ZIP.
2. Open the `SpectraSelect_Frontend` folder in VS Code.
3. Install/use the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. Login with any username and password `1234`.

## Included
- Authentication UI
- RF recommendation engine
- Custom weighting
- Leaflet coverage map
- FSPL calculator
- Battery-life estimator
- Radar comparison
- Searchable specification table
- CSV export
- Print/PDF report
- Analytics charts
- Responsive design
- API-ready folder structure
